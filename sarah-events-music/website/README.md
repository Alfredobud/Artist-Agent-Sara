# Website

This folder contains the first static version of Sarah Events Music's landing page.

## Files

- `index.html` — page structure and content
- `style.css` — responsive styling and visual system
- `script.js` — form simulation, localStorage lead capture, and small interactions

## Preview

```bash
cd sarah-events-music/website
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.

## Form Integrations to Add Later

The current form saves lead details to `localStorage` and shows a thank-you message. It includes code comments showing where to integrate Google Forms, Tally, Formspree, Airtable, Notion, Google Sheets, Zapier, or Make.

# Metrics

## Marketing

- Followers
- Reach
- Views
- Saves
- Shares
- Messages received
- Link clicks
- Website visits

## Sales

- Leads received
- Qualified leads
- Proposals sent
- Response rate
- Events closed
- Average value per event
- Closed revenue
- Commission generated

## Content

- Videos published
- Best video of the week
- Songs with the most engagement
- Highest-performing format
- Relevant comments

## Suggested Weekly Review

Use Friday to record the numbers, identify the best-performing content, update lead status, and choose one improvement for the following week.
